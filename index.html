This board syncs live between you and your wife through Firebase Realtime Database (free). One-time setup:

  1. Create a project at console.firebase.google.com (skip Analytics).
  2. Left menu → Build → Realtime Database → Create database → start in test mode.
  3. Gear icon → Project settings → Your apps → add a Web app (</>) → copy the firebaseConfig values below.
  4. Recommended database rules (Rules tab):
    { "rules": { "plans": { "$room": { ".read": true, ".write": true } } } }
    Open to anyone with the link — fine for a trip plan; tighten later if you like.
